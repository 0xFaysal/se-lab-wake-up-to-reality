# ParkEase BD — UI/UX Design System & Screen Catalog

[![Figma Design](https://img.shields.io/badge/Figma-UI%2FUX%20Design-F24E1E?logo=figma&logoColor=white)](https://www.figma.com/design/xpGwQGsxbzN8kQK0IubMPU/ParkEase-BD-%E2%80%94-UI-UX-Design?node-id=0-1&t=wANRYM1Cb6R2qjlc-1)

This directory houses the UI/UX design specifications, screen artifacts, visual workflows, and architectural design system for **ParkEase BD**.

---

## Directory Architecture

The UI design artifacts are organized logically by persona role and functional domain:

```text
UI/
├── public/                  # Public-facing views, marketing, landing page & authentication
├── guard/                   # On-site security guard portal & gate verification workflows
├── manager/                 # Property manager operations, space monitoring & support
└── owner/                   # Parking space owner portal & listings management
    └── add-parking-space/   # 8-step listing creation wizard
```
