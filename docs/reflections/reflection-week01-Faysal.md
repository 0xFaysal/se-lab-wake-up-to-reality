## The Joel Test

Which of the 12 steps would most software teams in Bangladesh fail, and why?

In the context of the software industry in Bangladesh, most teams struggle and fail at **Step 5 (Fixing bugs before writing new code)** and **Step 7 (Having a spec)** .

Due to tight client deadlines, high client pressure, and market competition, companies often prioritize shipping new features rapidly ("infinite defects methodology") rather than clearing technical debt or resolving existing bugs first. Furthermore, code is frequently written on the fly without a comprehensive, pre-documented functional specification (spec), leading to misaligned project scopes and poor code architecture.

## Most surprising from the Git workflows article

The most surprising thing was that there is no single "best" Git workflow. Instead, a team should choose a workflow based on its project size, release strategy, and collaboration style, because Git is flexible enough to support different development processes.

## A DevSecOps concept that connects to something you already knew

I already knew that CI/CD pipelines automate software building, testing, and deployment. DevSecOps extends this idea by integrating automated security checks, vulnerability scanning, and security testing into the same pipeline, making security a shared responsibility throughout the software development lifecycle instead of only at the end.
