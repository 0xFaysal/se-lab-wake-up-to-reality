# Week 01 Reflection — [Marjia Islam]

## The Joel Test
Most teams in Bangladesh would likely fail in step-7: do you have a spec? and in step-12: do you do hallway usability testing? Many small teams skip specs and jump straight to coding, since programmers generally prefer writing code over writing documents. And hallway usability testing also gets skipped because there's no spare time or culture of pausing to grab a random person and watch them use the software before shipping.

## Most surprising from the Git workflows article
The most surprising point is that Git has no official workflow. Git gives a lot of freedom in how changes are managed, so there is no single fixed way to use it.

## A DevSecOps concept that connects to something you already knew
DevSecOps treats security as a shared responsibility across the whole team instead of one isolated group at the end, which reminds me of how group projects work best when everyone owns quality together instead of leaving all the checking to one person at the last minute.

## One genuine question you still have
Joel wrote this test in 2000, long before Git, cloud tools, and free software like VS Code existed. Given how much has changed, is the whole 12-step test still a fair way to judge a team today, or does it need an update?
